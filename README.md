# OpenTacho releases

Downloads for OpenTacho, a desktop program for analysing digital tachograph
downloads (driver cards and vehicle units) against the UK drivers' hours,
working time and tachograph rules.

Get the latest version from the [Releases](../../releases/latest) page.

## Windows

1. Download `OpenTacho_<version>_x64-setup.exe` from the latest release.
2. Run it. It installs for your user account only, so no administrator
   password is needed. Windows may warn that the publisher is unknown: choose
   **More info → Run anyway**.

OpenTacho checks for a newer version each time it starts and shows it in
the notification bar; **Main menu → Check for updates** asks at any time.
Updates install in a moment and keep your library and settings.

Upgrading from 0.7.1 (the zip)? Install 0.8.0 once with the setup program;
your library is kept, and later versions arrive by themselves.

The `.sha256` file next to each download lets you check that it arrived
intact.

Infringement results are an aid for checking records, not legal advice.
